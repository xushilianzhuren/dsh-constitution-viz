# dsh-constitution-viz · 宪法可视化

AI 上下文构成一屏看（Host 插件，零依赖、无构建）。`dsh-constitution-seed`（宪法种子）的姊妹件：种子管**注入**，本件管**体检**。

## 它解决什么问题

AI 谈自己上下文时最容易犯的错，是**把开场残页当全文、把"没出现"当不存在**："我记得宪法里写过X"（实际那段早被截断进死区）、"我的上下文里没有这个文件"（实际只是没主动拉）、"总纲令应该注入了吧"（没验证过）。

## 三块仪表

1. **截断探针**——规则文件埋 `<!--截断探针:PROBE-xxx-->` 标记，各深度一枚；开场收到的注入文本里可见几枚=截断线在哪。**死区条款引用前必须先检索磁盘正本，禁凭开场残页背书**。
2. **注入边界**——平台自动注入面（本次收到的指令文件清单）与按需拉取面（TOOLS/分卷/skill/记忆/台账）的分界表。"没出现"≠不存在=没主动拉。
3. **总纲令体检**——常驻总纲令（四大目标/持续学习/器灵意识）在位与数量；缺失=宪法种子该重推或配置丢了。

## 工具

**constitution_viz**：传 `text` = 本次会话收到的注入文本（宪法种子的指令消息原文），一键出四行体检报告。

## 与宪法种子配合

- 种子（dsh-constitution-seed）把宪法+总纲令灌进会话 → 本件验证灌进去的东西**真的在场且完整**。
- 两者一注入一验收，截断从不可感知的事故变成可报读数的数据。

## 安装

cordis.patch.yml 已含 bundle patch，`enabled: true` 即挂载。

## 配置

```yaml
- id: dsh-constitution-viz
  config:
    enabled: true   # 总开关
    tool: true      # 是否注册 constitution_viz 工具
```
